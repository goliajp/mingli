# 已经查明、并且**不是守卫缺口**的漏网。
#
# 变异扫描每轮都会把它们重新报一遍，而判断它们要花的功夫远超扫描本身：
# 一条 `+ 180` 改成 `- 180` 看起来像缺口，证明它在模 360 下恒等要另花一段时间。
# 这份清单把那段功夫存下来，`mutants.sh` 拿它对账，只报没见过的。
#
# 它**不隐藏**任何东西：每轮仍然完整扫，清单只负责把已知的挪到一边，
# 并且反过来查——清单里的条目若不再出现（被真正拦住了，或代码没了），也会报出来，
# 免得它变成一份越攒越旧的免罪符。
#
# 每行：<crate> <文件> <变异描述>|<条数>|<理由>
# 描述取扫描输出去掉行号列号的那一段，故改代码不会让清单失效。
